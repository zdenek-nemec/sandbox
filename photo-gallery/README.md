# Photo Gallery

This is Cursor demo project. The entire first version of `main.py` was generated by AI.

This is a small Python Windows application for displaying pictures. Simply start the application and it will display
random picture from `pics` folder. Supported formats: `jpg` and `png`. Window displaying the picture has no menu and
very thin borders. The window can be moved by left mouse button click-and-hold and dragging to a new place. The window
can be resized by left mouse button click-and-hold on border and moving. To exit the application simply focus on it and
press `Esc` on the keyboard.

## Controls

* `Esc` - exit the application
* `R` - rotate the picture 90 degrees
